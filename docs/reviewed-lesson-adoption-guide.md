# Adopt a Reviewed lesson into another project

Open the configurator Project lesson register as an active administrator.

1. Choose Adopt a reviewed lesson.
2. Select the exact current Reviewed source version and inspect its actual content. Draft and Archived sources cannot be newly adopted.
3. Manually choose a different visible target project and enter the actual adoption reason. This deliberately shares the reviewed source content/provenance with that target project's assigned authorized managers.
4. Create target lesson Draft. The existing target register lets its manager adapt the Draft; an administrator reviews the actual target lesson separately. Source review never bypasses target review.

The immutable receipt stores the original source, actual review revision, initial target Draft, actual adopting administrator/time/reason and canonical request. Export visible lesson adoptions CSV retains these snapshots for only visible target projects. Clients and unrelated/source-only users do not gain target receipt access; managers do not gain a global reviewed-source catalogue.

Exact failed retries preserve identity/inputs. Changed requests use a new identity. The same source-version/target combination cannot be duplicated. Later target editing/review or source archival never rewrites the receipt or gets reverted by an old retry. A newer Reviewed source version can be deliberately copied as a new target Draft; it does not automatically update previous targets.

This action shares knowledge only. It creates no execution tasks, standards/templates, salary/KPI policies, scope, budgets, assignments or closure. Such changes require their own documented review/application workflows. Client live/role/export/device acceptance remains separate.
