# Certificate renewal history

First complete a separate actual assessment, independent Approved Pass review and HR/Admin certificate issuance using the existing [certificate records](competence-certificates-guide.md) workflow. Development does not supply people, results, business standards, reviewer/issuer assignments or renewal outcomes.

Open **Overtime & performance → Certificate renewals**, then **Load certificate renewals**. Active employees can inspect their own certificate history; current HR/Admin can coordinate and inspect certificate renewal history. Certificate and predecessor selections start blank. Choose the actual issued certificate to inspect and **Inspect selected renewal history**. Employees have read-only history and private evidence export, with no HR predecessor directory or link controls.

Current HR/Admin selects the **Actual previous certificate**, enters a real **renewal history reason**, then **Link actual separately issued renewal**. The new certificate must already exist from a different actual assessment for the same employee and competency. It must be valid, unrevoked and unexpired with current independently Approved Pass evidence, current employee/assessor/reviewer eligibility and exact current Active criteria. The predecessor must be distinct, for the same actual employee/competency, and issued no later than the new certificate. A historical expired/revoked predecessor may be retained as renewal evidence; linkage never restores or changes it.

The server prevents duplicate current predecessors/successors, cycles, changed request reuse and stale sequences. There is no automatic renewal window, grace period, assessment copying, expiry extension, automatic certificate revocation/restoration or second learning/skill credit. Linking preserves both full certificate snapshots, original assessment/receipt/review/issuer/time/validity evidence, statuses at linkage, actual action account, server time and reason. All original certificates and expiry/warning dates stay immutable.

For a wrong link, current HR/Admin enters an actual reason and chooses **Withdraw renewal link with retained history**. It retains the old event and both certificate snapshots. Refresh and manually select a replacement predecessor/successor through a fresh action. HR/Admin can withdraw historical links after employee/source eligibility changes; fresh relinking still requires current source eligibility. Exact acknowledgement of an older link never recreates a withdrawn link.

After an uncertain error, refresh the selected renewal evidence. Unchanged request identity/sequence is retained; a committed event reconciles from immutable history without duplicate action. Errors remove failed private details/register/export. Changed accounts/permissions, switching away and back, unmount and delayed responses cannot restore old private views. **Export private renewal evidence CSV** preserves accessible immutable link and withdrawal records and both certificate snapshots. Inspect either linked certificate to see its related history.
