# Actual competence assessments

Open **Overtime & performance → Competence assessments**, then **Load competence assessments**. Active internal staff see only their current scoped assessments: an employee's own records, a currently designated assigned assessor's eligible employee records, or existing HR/Admin oversight. Clients/external accounts, disabled accounts and unrelated staff cannot read assessment records. Site Engineer/senior-technician designation does not open the employee directory or global criteria/qualification history.

Existing HR/Admin coordinators choose **Assign an actual employee assessment**. Employee, assessor and competency selections start blank. Select the actual active internal employee, an actual currently designated Site Engineer/senior technician and the exact latest Active competency revision. Inspect the criteria and provide the actual assignment reason. No reviewer or employee is chosen automatically, and the assignment grants no project/global role. The server freezes the actual employee/assessor identity, criteria/checklist/mandatory flags, quiz/pass mark, validity/warning settings, current qualification reference and coordinator/server time/reason. Private administrator qualification/criteria notes are excluded. An assignment does not assess or certify anyone.

The actual selected assessor opens their assessment and enters Pass, Fail or draft Unrecorded for each practical step. Quiz score starts blank and is available only when the pinned competency enables a quiz. **Save actual observation draft** permits partial observations and never awards Pass. Reopening a saved Draft loads its actual saved observations; newly assigned assessments contain no copied outcomes.

**Record actual assessment** requires an actual Pass/Fail for every checklist step (including nonmandatory steps) and an actual percentage score if the quiz is enabled. Pass requires all mandatory practical steps to pass and, when the quiz is enabled, score >= the pinned administrator pass mark. A nonmandatory Fail alone does not fail those pass conditions. A competency without a quiz needs no invented quiz score and rejects one. The server computes the outcome from frozen criteria and actual inputs; the client cannot supply a pass mark, mandatory flag or final outcome. No rounding, salary, working-hour or target policy is added.

Recording requires the current actual assigned assessor, active internal employee, current eligible assessor designation and exact current available pinned criteria. Criteria changes/inactivation make the assessment historical and block fresh results: HR/Admin cancels and explicitly chooses current criteria for a replacement. Revoking a designation removes the assessor's private scope and mutation/old-retry authority; restoration can restore actual eligibility and a new recorded receipt retains the actual current qualification reference while original assignment evidence stays unchanged. Disabled/transferred employee or assessor accounts lose their staff scope; HR/Admin retain authorized historical oversight.

Recorded outcomes cannot be edited in place. They remain uncertified; load independent review for the current review status. For an incorrect assignment or observation, HR/Admin uses **Cancel assessment with retained history** and an actual reason, then creates a separate manually selected replacement assessment. Cancellation never deletes or reclassifies prior recorded proof. It cannot award certification, reverse financial/learning credit or automatically copy results. Ordinary assessors/employees have no coordinator cancellation power.

Refresh the selected assessment after an error. Unchanged requests retain their identity/version; exact acknowledgements cannot create duplicate receipts. Refresh reconciles a committed uncertain action from its immutable event ID and clears already-saved inputs. Changed fields/reasons are new requests. If another revision supersedes an unsaved action, inspect history and explicitly reopen the current assessment before a fresh action. Failed reads, changed accounts/permissions, returning to a previous account, unmount and late responses suppress old private views, forms, exports and refetches.

**Export private assessment evidence CSV** retains the accessible original assignment/criteria and immutable assignment/draft/record/cancellation receipts with actual actor/server time/reason. The latest outcome on a cancelled assessment is labelled historical. This register creates no certificate, employee skill, learning/activity/pay/cash record or resource suggestion/assignment. Current ordinary training attendance, credit and Finance remain separate.

No actual people, standards, results or production test fixtures are inserted by development. Signed-in populated role/workflow/private export/device acceptance remains client-owned and pending; competence, training and CRM are not complete.


Independent review: open an assessment and **Load independent review**. HR/Admin selects the actual current Team Lead or PM in the blank reviewer field and enters a real assignment reason. Only actual active role membership qualifies; Admin/HR alone do not. The reviewer must differ from the assessor. No reviewer is selected automatically. Assigned reviewers use the same assessment register and gain only their assigned eligible Recorded assessments; they receive no coordinator directory or private administrator qualification notes.

The selected reviewer inspects the frozen recorded observations, exact receipt, criteria and outcome, then **Approve exact recorded evidence** or **Return recorded evidence with reason**. A correctly graded Fail can be reviewed and remains Fail. Review never issues a certificate or employee skill. Exact receipt/version/sequence and current criteria, actual employee/assessor eligibility and reviewer role are enforced by the server. Current approval disappears if these prerequisites are revoked, disabled, superseded or cancelled, while original history remains. Restoration rechecks current eligibility without fabricating another event.

The current reviewer or HR/Admin can **Withdraw review with retained history** and an actual reason. HR/Admin may withdraw stale/cancelled reviews for historical correction. Withdraw before manually selecting a replacement reviewer. A returned assessment is not editable: use reasoned HR/Admin cancellation and a new manual assessment when observations require correction. **Export private independent review CSV** retains the exact recorded receipt and immutable assignment/review/return/withdrawal actor, server time and reason. Refresh after uncertain errors to reconcile an action already present in history; unchanged retries cannot duplicate the event. Signed-in acceptance remains pending.


Certificate issuance/expiry is a separate bounded DEV-027 increment: [Competence certificate records](competence-certificates-guide.md). HR/Admin explicitly issues only from a current independently Approved Pass receipt; dates/settings and original evidence are frozen, with private own/HR access and reasoned immutable revocation. No automatic renewal, certificate-backed skill/profile/resource suggestion or training-credit effect is added in that increment. Both requirement documents contain validation/release and precise resume; earlier future-work paragraphs describe historical increments. Client acceptance remains pending.
