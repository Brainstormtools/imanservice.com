# Private finance evidence files

Expense receipts and loan/advance agreement files are optional evidence alongside the existing text reference. Uploading proof never approves a document or transfers money. Signed-in/browser/export/device acceptance remains client-owned.

## Loan and staff-advance agreements

Existing Accounts/Admin users open **Finance & expenses → Loans & advances**, select an actual record and explicitly choose **Load loan agreement files**. The file panel is not available to ordinary staff, project managers, clients or an advance recipient solely because they are the recipient.

On Draft/Rejected records, choose an actual PDF/image, enter the actual upload reason and upload. Existing technical limits are 10 MB per file, 10 active and 20 registered files including retained history. The portal validates filename/extension/MIME and file prefix, uses a private bucket and never overwrites an existing object. A lost response can be reconciled by loading files and retrying the exact upload; changing file/reason while an upload is unresolved requires reconciliation or explicit discard. Discard applies only to an owned unregistered upload.

Download uses current authenticated Accounts/Admin access. Exclude/restore needs an editable source/version and reason; original registered files and action history stay private and retained. Revoked access removes even an uploader's registered/orphan download rights. Missing/changed metadata is flagged and prevents download/restoration or review as applicable. A file upload is evidence, not proof that somebody legally signed or approved the agreement.

Submitting and independently approving a loan/advance freezes the exact current file basis with complete source/actor/server-time evidence. Text-reference-only records remain valid; no historical proof approval is fabricated. Submitted/Approved/Cancelled records are read-only for file changes; use the existing rejection/return workflow before draft corrections. File changes advance the loan version, so refresh stale financial forms before acting. Loan principal, repayment terms, approval roles, cash posting/reversal and payroll rules are unchanged.

**Export private loan agreement file register CSV** includes the visible file register and immutable attachment/exclusion/restoration/submission/approval snapshots. Treat it as private financial information. Cash-movement file uploads remain a separate development increment; no cash transfer is initiated by agreement-file actions.
