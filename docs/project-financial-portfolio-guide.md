# Project portfolio financials

Open Finance → Portfolio financials as an active administrator or team member with Accounts finance.manage permission.

The report shows one current authoritative project financial result per PKR project. Observation time, Karachi business date and excluded non-PKR project count describe coverage. Missing values remain Not recorded; actual zero/negative amounts remain visible. The report does not convert currencies or invent missing budgets/revenue.

Search by project/customer or choose an actual recorded project status. Export filtered portfolio financials CSV includes exactly the visible rows, current measures, recorded dates, full current per-project JSON and budget/reference/limitation basis. Accepted additional quoted gross is reference only; it is not added to operative contract revenue. Profit before unrecorded costs and margin remain provisional.

Refresh obtains current source records and resets filters. Failed reads remove private results; download failures block exports until refresh. Access changes clear private data and pending old responses are ignored. Confirmed empty coverage is separate from unavailable data.

This report changes no financial records, costs, cash, inventory or assignments. Historical actual completion/date variance, full tax treatment, operative office distribution and immutable final settlement remain pending. Client signed-in/export/device acceptance is separate.

## Choose financial measures

Use Financial measure view after applying any project/customer/status filters.

- Overview keeps the original contract/planned/recorded/provisional/outstanding/cash summary.
- Budget and costs separates original conversion, released additional and effective plans, material/labour budgets, actual saved costs and individual hours, utilisation and source profitability.
- Cash and commitments separates purchase commitments and material bill liabilities from actual supplier/expense cash and loan/advance movements. Commitments/bills are not added to recorded costs again.
- Quote references shows actual accepted-offer count and quoted subtotal/tax/gross/WHT/receivable as references only.
- All recorded measures shows each of the 43 source financial fields once.

Units distinguish PKR, percent, counts and hours. Export filtered portfolio financials CSV follows the selected view's visible columns and filtered project rows, retaining the selected view and complete current project JSON/basis. Switching views does not recalculate financials or make another read; refresh resets to Overview and clears project/status filters.

Historical actual-date variance remains separate pending work.

## Category costs

Select Category costs to view actual recorded category rows for the currently filtered projects. This sixth view preserves the five scalar views/43 measures. Approved expenses, net stock, saved hourly labour and recorded category cost are retained exactly as the source reports them; repeated source rows stay separate. No commitments/vendor liabilities or unapplied office distributions are added.

Coverage lists each filtered project with its recorded category row count, confirmed empty categories or unavailable category source. Incomplete/malformed category arrays are unavailable; they do not create zero costs or partial rows. Missing individual amounts stay Not recorded.

Export filtered portfolio category costs CSV contains only visible actual category rows, original row positions, full category/project source JSON, the exact filtered-project coverage JSON and observation/budget/limitation basis. Project recorded cost is a repeated reference only. If no category rows exist, export is disabled; the coverage list explains confirmed empty versus unavailable sources.

Filters scope both category rows and coverage. Switching views makes no extra read. A download error blocks portfolio controls until refresh; refresh clears filters and returns to Overview. Access changes clear category data/export alongside the full private portfolio.
