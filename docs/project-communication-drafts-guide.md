# Manual communication plan drafts

In the Configurator project charter register, an active administrator or assigned project manager selects New communication plan draft. Choose an actual current charter and manually enter title, purpose, channel, cadence, recipient name/audience and optional recipient context/contact reference. The optional planned date starts blank. Recipient rows are text references, not user-account assignments. Saving records the displayed exact source charter version and requires your actual revision reason.

A draft preserves its full source snapshot. Revise communication draft keeps the original project/charter identity, requires a new reason and explicitly captures the current displayed source version. Refresh after a stale source/version rejection. Exact unchanged failed requests can be retried safely; changed creation payloads receive a new identity. Archived source charters prevent further edits; earlier evidence stays readable.

Draft and history CSV exports retain manual recipients, source, actual author/actor/time/reason and immutable revision evidence within the visible project scope. Client and ordinary worker access is unavailable.

Draft saving and administrator review/return are separate actions. An active administrator chooses Review this communication plan version or Return this communication plan version and supplies the actual reason. Review requires an exact current Reviewed source charter captured in the draft; refresh and explicitly revise stale source evidence first. Return can document corrections even after source changes or archival. A later draft version is Not reviewed until explicitly reviewed. Managers can inspect prior full review/source archives and export the scoped review CSV. Manual occurrence evidence is recorded separately as described below. No recurring sends, email/SMS/WhatsApp delivery, tasks, reviewer assignments or client publication/sign-off are created. Actual business content must be entered by authorized users.


## Manual occurrence evidence

Record communication occurrence is available only for the exact current reviewed plan and unchanged Reviewed charter. Enter the actual occurrence timestamp with an explicit timezone (ISO format), channel, participants/audience, outcome, optional evidence reference and the actual recording reason. The timestamp starts blank; future occurrence times are rejected and saved actual times normalize to UTC. Saving records your supplied evidence and does not send or independently verify communication.

Correct communication occurrence appends a factual correction with a new reason to the latest unsuperseded evidence. It retains the original frozen plan/version/review even when the plan later changes or its source is archived. Original evidence remains readable and cannot be edited/deleted. Only the latest correction can be corrected again. Historical corrections do not authorize new occurrences against an unreviewed/returned/stale plan.

Export communication execution CSV retains original/correction identities, actual data/recorder/time/reason, full plan/review/source snapshots and canonical requests within the visible project scope. Recipients, outcomes and evidence references are manually recorded; no real data is supplied by this release.
