# Private client charter copy drafts

In the project charter register, an active administrator or assigned project manager chooses New client charter copy draft and selects an actual Reviewed charter. Manually enter client-facing title, objectives, scope, deliverables and communication wording plus an actual revision reason. All wording starts blank. Private source stakeholders and review notes are not automatically included.

The private draft freezes the exact source charter. Revise client charter copy keeps source/project identity, requires a new reason and explicitly captures the displayed current Reviewed source version. Refresh after source/version changes. An Archived/Draft source cannot support new saves. Earlier exact unchanged requests can be retried safely without reverting later revisions.

The copy and history exports are private and include full internal source provenance, actual actors/times/reasons and immutable revisions. They are intended for authorized internal users. Clients cannot read these tables or exports.

Draft preparation and review stay separate from publication. Administrator review/return is separate from client publication/withdrawal and client sign-off. Client sign-off remains pending. Draft saving and internal review do not approve contractual scope, alter budgets, assign signers, deliver messages or give clients access. Actual business wording is supplied by authorized users.


## Internal copy review

An active administrator opens Review this client charter copy version or Return this client charter copy version and supplies the actual reason. Review requires exact current Reviewed source evidence captured in the copy; refresh and explicitly revise a stale copy first. Return can record corrections after source changes/archive. Later copy versions need new review; previous review/source evidence remains immutable. Assigned managers can inspect the scoped review archive and private CSV without administrator decision controls. Review does not publish or obtain client sign-off.


## Publication and withdrawal

An active administrator confirms the displayed actual project client company, then selects Publish reviewed charter version and enters an actual publication reason. The exact latest Reviewed copy and unchanged Reviewed source are required. Only title, objectives, scope, deliverables and communication wording enter the fixed client copy, alongside publication/project/client identifiers, names and status/times. Check all manual wording for client suitability. Private source/review/actor/reason archives remain separate administrator evidence.

Clients read/export Published client charters from My contract documents (Contract documents for administrators). Withdraw open charter publication requires the exact publication version and a new manual reason; withdrawn copies stay historical and cannot be republished as the same copy version. Explicitly review a newer manual copy version to publish again after withdrawal. Later private edits/source archive never silently rewrite client wording. A current client-company membership is required; changing companies revokes old-company visibility.

Publication does not obtain client acceptance or change operative scope/budget. Client sign-off remains pending. No email/SMS/WhatsApp is sent.
